# lales-house-design

Recorrido visual de Casa Lales, basado en fotografías y medidas aproximadas.
Incluye exterior, cuarto, sala y comedor, cocina y planta alta.

Página prevista: https://alex-carrera.github.io/lales-house-design/

El archivo `index.html` contiene el recorrido completo y funciona sin instalar
bibliotecas ni descargar recursos externos. Requiere un navegador con WebGL
para mostrar materiales, transparencias y sombras.

## Actualizar

Sustituir `index.html` por la nueva exportación del recorrido y guardar el cambio
en `main`. GitHub Pages publica desde la raíz de esa rama.

Las fotografías originales y los archivos editables de FreeCAD se conservan
por separado en el proyecto local.
